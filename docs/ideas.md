# 🗺️ Ideas for new content

Things that would fit the mod and are not built yet. They are ideas, not promises: nothing here is scheduled, and each one would get its own feature page when it is made. Back to the [main page](../README.MD) · [Documentation](README.md)

Everything below follows the [biome rule](../.github/copilot-instructions.md#game-balance-guidelines): content belongs to the biome where it is found, and a recipe never uses materials from a later biome.

##  Horns and companions

The [Dragon Horn](monsters.md#the-dragon-horn-a-white-dragon-at-your-side) calls a White Dragon, and the [Summoning Horn](difficulty.md) calls the black beasts.

- A horn for a different companion, for example a wolf pack on land or an escort for a ship.
- Letting the [dog](dog.md) and the dragon share progress with the [Saga](saga.md) and the [Bestiary](bestiary.md).
- More for the dog to do: new tricks and small jobs at home.

## ⚙️ Settings presets

Every setting can be changed, and there are many of them. The HUD already has a `Preset`. A preset for the whole mod (*Vanilla+*, *Standard*, *Hardcore*) would set many values at once in the [settings window](progression.md), with the server deciding.
